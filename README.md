# Equity Trading & Trade Lifecycle Management — Business Analyst Project

## Project Overview

An end-to-end Business Analyst portfolio project covering the complete equity trade lifecycle:

Order → Execution → Clearing → Settlement → Exception Management → Reporting

## Business Analyst Work

- Business Problem Analysis
- BRD & FRD
- User Stories
- Use Cases
- Acceptance Criteria
- Process Mapping
- RTM
- SQL & Excel Analysis
- Dashboard & KPI Analysis
- UAT & Test Cases
- Agile Backlog
- Risk Register
- Business Insights

## Analytics

The project analyzes:

- Trading activity
- Order and trade volumes
- Trade value
- Execution performance
- Settlement success
- Failed and pending settlements
- Operational exceptions
- Security and sector performance

## Dashboard

The project includes an Interactive Trade Lifecycle Analytics Dashboard with:

- Total Orders
- Total Trades
- Total Trade Value
- Execution Rate
- Settlement Success Rate
- Open Exceptions
- Settlement Status
- Exception Severity
- Top Securities

## Tools

SQL | Excel | Data Analysis | Dashboarding | Agile | UAT | Business Analysis

## Disclaimer

This is an independent portfolio project. Meridian Capital Securities is fictional and all datasets are synthetic.
